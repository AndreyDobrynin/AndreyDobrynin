## 🚀 Мои проекты

### ✂️ Автоматизация барбершопа
Учебная конфигурация для автоматизации работы барбершопа: предварительные записи, продажи, складской учёт, закупки, расчёт заработной платы и аналитическая отчётность.

### 💅 Автоматизация салона красоты
Конфигурация для ведения клиентской базы, учёта услуг и товаров, финансовых операций, работы сотрудников и аналитики.

### 🐾 Автоматизация груминг-салона
Решение для учёта клиентов и питомцев, предварительных записей, закупок, складских операций и организации повторной записи через бизнес-процессы.
